# Install 0x Sneaky Alpha on your iPhone

You need the app's web address (the HTTPS link where it's hosted).

1. Open **Safari** on your iPhone (it must be Safari).
2. Go to the 0x Sneaky Alpha link.
3. Tap the **Share** button (square with an arrow).
4. Scroll down and tap **Add to Home Screen**, then **Add**.
5. Open **0x Sneaky Alpha** from your Home Screen. The neon intro plays.
6. Follow the welcome steps: your name (optional), pick a provider, paste your API key, pick a model.
7. Start chatting.

## Tips

- **Check a provider:** Settings → Providers → pick one → **Test connection**. "Connected" means it works on your phone.
- **Lock your keys:** Settings → Security → set a passphrase. You'll enter it each time the app opens.
- **Back up chats:** Settings → Data → **Export chats** → save to Files. Import the file the same way.
- **Updates:** close the app fully and reopen it to pick up a new version.
- **Keep your data:** don't delete the Home Screen app or clear Safari website data, or your chats and keys go with it. Export first.
- **Keep the app open while it answers.** iOS pauses web apps in the background, which can cut a reply short. Tap ↻ to regenerate.
